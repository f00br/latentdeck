# LatentDeck 0.1.0-preview.1

`v0.1.0-preview.1` is an unsigned Windows prerelease of the LatentDeck
applications, Latent Cartridge tooling, realtime Deck system, and extension
SDKs. It is an unsigned preview intended for artists and developers who can
verify release hashes and accept the Windows unknown-publisher warning.

## Release identities

| Surface | Version |
| --- | --- |
| LatentDeck App and LatentPlayer API | `0.1.0` |
| Windows installer build | `0.1.0+1` |
| LC specification and H3 profile | `0.1.0` |
| H3 Codec Pack | `0.2.1` |
| H3 codec adapter | `0.2.0` |
| Bundled D2 and Q4 Deck Packages | `0.2.1` |
| D2/Q4 operators | `0.2.0` |
| Codec and Deck Python SDKs | `0.2.0` |
| Worker Protocol | `2` |

Package and API versions are independent. In particular, H3 pack `0.2.1`
contains adapter `0.2.0`.

## Highlights

- Save generated or imported H3 representations as validated, data-only `.lc`
  cartridges.
- Play a cartridge through an exact enabled Codec Pack in LatentPlayer.
- Organize cartridges with Library, Collections, tags, favorites, Recent,
  search, and manual ordering.
- Perform realtime latent synthesis through installable D2 and Q4 Decks.
- Record the post-operator latent state with Snapshot or bounded Live Capture
  and immediately reuse the resulting cartridge.
- Present decoded output in-window or fullscreen, publish an intrinsic Spout2
  texture, or record video-only H.264 MP4.
- Install external `.ld` Decks and `.ldcodec` Codec Packs through one
  exact-hash, immutable-version, explicit-enable lifecycle.
- Develop with typed Cartridge, Deck, Codec, and Comfy Toolkit Operator APIs;
  machine-readable schemas; scaffold/build tooling; and CPU-first examples.
- Begin with a separately hosted, pinned three-cartridge [H3 demo
  pack](../guides/DEMO_CARTRIDGES.md) for Player and D2/Q4 evaluation.

Always also download `LatentDeck-0.1.0-preview.1-SHA256SUMS.txt` and verify the
selected ZIP before opening it. GitHub's automatically generated source
archives are for source builds and are not part of the Windows quick start.

The Artist Starter contains the unsigned LatentDeck and LatentPlayer
current-user installers plus H3 Codec Pack `0.2.1`. Extract the entire ZIP
before running setup: its `H3-Codec` directory keeps the setup beside the exact
hash-bound `.ldcodec`, and its internal checksum covers every bundled file
except that checksum manifest itself. The separate Recorder ZIP carries
prebuilt, hash-bound Cartridge SDK and Safetensors wheels for Windows x64
CPython 3.12 and 3.13. The Developer Kit remains optional for artists.

Download all required files from the same release and follow [Windows
installation](../guides/WINDOWS_INSTALL.md).

## Important limitations

- This preview is not Authenticode-signed. Windows may identify the installers
  as from an unknown publisher.
- The initial runtime path is Windows x64 with an NVIDIA CUDA device and H3.
  Performance is certified only for exact measured configurations.
- The H3 pack does not include a decoder weight, generator, ComfyUI, model
  asset, or cartridge. The user selects a compatible external TAEH3 decoder.
- Audio latent data may be preserved, but audio playback and synthesis are not
  implemented. MP4 output is video-only.
- Direct synthesis requires exact profile, geometry, timing, and runtime ABI
  compatibility. No hidden resize, crop, alignment, cast, re-encode,
  substitution, or fallback is performed.
- Installed Decks, Codec Packs, and research operators are executable-code
  trust decisions. Package validation and worker containment are not a
  security sandbox; publisher labels are self-declared in this preview.
- Demo cartridges are distributed separately from the source and release. The
  pinned pack has published hashes and exact H3 compatibility metadata and is
  licensed under CC BY 4.0. Credit **f00br** and **LatentDeck Demo LC Pack**,
  link the dataset and license, and indicate whether changes were made when
  sharing or adapting the media.

## Developer surface

The Developer Kit contains the same project wheels and CLIs used by the public
examples, plus package schemas, a compatibility manifest, SBOM, notices, and
bootstrap instructions. It also carries the exact Comfy Recorder bundle from
the release set. Package registries are not used for this preview;
PyPI/crates.io publication is deferred. In particular, Comfy Registry/Manager
installation remains unavailable until the native Cartridge SDK has an
approved publication/configuration route; use the self-contained bundle.

Start with the [developer hub](../developers/README.md). The extension manager
can scaffold and build a Deck or Codec Package without editing the first-party
applications. Cartridge genealogy, starter Deck, and synthetic Codec examples
use bounded generated data rather than checked-in latent media.

## Upgrade and removal

Applications and H3 are independent current-user installations. Removing one
application preserves the other application, Codec Packs, Decks, cartridges,
Library data, and decoder selection. H3 versions install side by side and are
removed by exact version through Windows Installed Apps; an existing installed
version is never overwritten in place.

Close active Player/Deck sessions before disabling or removing the exact
extension version they retain.
