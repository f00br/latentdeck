# Interface reference policy

The owner may keep rough interface sketches in this directory in a local
working copy. PNG files in this directory are intentionally ignored by Git and
are not part of the public source tree.

Local sketches may be used only for broad visual mood: an instrument-like
language and distinct Library, Dual Deck, Quad Deck, and Player experiences.
They are not executable specifications, engineering layouts, pixel-perfect
requirements, implementation evidence, branding, supported feature lists,
performance claims, or format contracts. Behavior and validated synthesis
contracts are fixed first; the UI is then adapted to them.

In particular, fictional deck types, audio controls, labels, dimensions,
cartridge names, and values shown in a sketch must not be copied into the
product. Release documentation must use original screenshots of the working
applications rather than these local files.
